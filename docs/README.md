# Outremer docs

Index of the design and research docs. Locked rules live in the living files below. `docs/archive/` is for things we don't need to move forward, kept so we can look back.

## Living
- [DECISIONS.md](DECISIONS.md) — the decision log: every locked decision as a numbered entry (D-00001…), grouped by topic, with what replaced what.
- [GAME-BRIEF.md](GAME-BRIEF.md) — one-page brief, as of Stage 3, with later locks noted there.
- [DESIGN.md](DESIGN.md) — locked system decisions (pillars, kit template, races, combat rules, art scale).
- [TASKS.md](TASKS.md) — open design questions (Now / Next / Waiting / Parking lot).
- [ROADMAP.md](ROADMAP.md) — stages, done-when, and the parking lot for build ideas.
- [SLICE-PLAN.md](SLICE-PLAN.md) — Stage 4 vertical-slice milestones.
- [WORLD.md](WORLD.md) — lore: races, places, culture, look notes.
- [CLASSES.md](CLASSES.md) — class kits and the older class-list draft.
- [STORY.md](STORY.md) — story bible (locked beats and open story questions).
- [CHARACTERS.md](CHARACTERS.md) — character briefs for writing and art.

## Conventions
- **American spelling everywhere**: chat, docs and code (Cletus, 2026-11-19; D-00209).

## Future (not written yet)
- `ITEMS.md` (or `EQUIPMENT.md`) — item and teaching-gear lists, once shops and loot are designed. The slot and teaching rules already live in [DESIGN.md](DESIGN.md) (unit kit template).
- `BESTIARY.md` — enemy kits, once those are designed. The names (Imp, Fiend, Demon, and so on) already live in [DESIGN.md](DESIGN.md) (bestiary terms).
